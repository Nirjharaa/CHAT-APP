Real-time Chat Application with Translation | MERN, Socket.IO, Microsoft Translator API
I designed and implemented a real-time chat application using the MERN stack, incorporating Socket.IO for seamless communication and Postman for backend testing. To enhance cross-language communication, I integrated the Microsoft Translator API for real-time language translation. The application features a responsive and aesthetically pleasing user interface, achieved using Tailwind CSS and DaisyUI. Additionally, I deployed the application on Render. Later, I recreated the chat application using ChatEngine.io with React and Node.js.
