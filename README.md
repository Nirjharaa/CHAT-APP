Real-time Chat Application with Translation | MERN, Socket.IO, Microsoft Translator API
• Designed and implemented a real-time chat application using the MERN stack, incorporating Socket.IO for seamless
  communication and Postman for backend testing.
• Integrated Microsoft Translator API for real-time language translation, enhancing cross-language communication.
• Applied Tailwind CSS and DaisyUI for a responsive and aesthetically pleasing user interface.
• Also deployed the application on render.
• Recreated the chat application using ChatEngine.io with React and Node.js.
